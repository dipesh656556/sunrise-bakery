# Sunrise Bakery Manager (Android)

Bakery orders, income & expense, reports, backup/restore and WhatsApp "cake ready" messages.

## Get the APK
Every push to `main` builds the app automatically.
Open the **Releases** page of this repository and download `sunrise-bakery.apk`, then open it on your Android phone and allow "Install unknown apps" when asked.

## Change the app
Edit files inside `www/` (the app itself: `index.html`, `config.js`), commit, and a new APK is built in about 5 minutes.

## Share data between phones
Follow `www/SETUP-GUIDE.md` step 1 (free Firebase), paste your values into `www/config.js`, and commit.
